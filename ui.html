Google Sheets Setup:
1) Go to console.cloud.google.com/apis/credentials
2) Create project → Enable Drive API + Sheets API
3) OAuth consent screen → Add your email as test user
4) Create OAuth Client ID (Web) → Add http://127.0.0.1:3000 as authorized origin
5) Create a Drive folder → paste its ID below

User permissions:
• Share the Drive folder with other users (Editor = read+write, Viewer = read-only)
• Per-table access: create separate spreadsheets and share individually
• Add each user's email to OAuth consent screen → Test users
CRDT + Drive Sync Setup:
1) Same Google Cloud setup as Sheets (OAuth + Drive API)
2) Create a Drive folder → paste its ID below
3) Data stays in browser IndexedDB (instant), syncs to Drive every 30s

User permissions:
• Share the root Drive folder for full access to all tables
• Per-table access: share individual sync/{tableName}/ subfolders
• Users only see/edit tables whose sync subfolder is shared with them
• Add each user's email to OAuth consent screen → Test users
Firebase Setup:
1) Go to console.firebase.google.com → Create project
2) Firestore Database → Create database (production mode)
3) Authentication → Sign-in method → Enable Google provider (set support email)
4) Authentication → Settings → Authorized domains → Add your hosting domain
   (e.g. 127.0.0.1 for local dev, yourusername.github.io for GitHub Pages)
5) Project Settings → Your apps → Add Web app → Copy config JSON
6) Paste config JSON below and click Start
(For production: place firebase-config.json in the hosting root — users won't need to paste)
After first sign-in:
7) Firestore → Rules → Publish (start with open rules, then restrict per-user):
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}
8) To restrict per-user: go to Settings tab → copy your Firebase UID → update rules:
match /{document=**} {
  allow read, write: if request.auth.uid in ['YOUR_UID_HERE'];
}
9) Use Settings → Import from JSON to load schema + data.
