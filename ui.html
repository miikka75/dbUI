Google Sheets Setup:
1) Go to console.cloud.google.com → Create or select project
2) APIs & Services → Library → Enable Google Drive API + Google Sheets API
3) OAuth consent screen → Get Started → Set app name, support email
4) Audience → Add test user emails)
5) Clients → Web Application → Name → Authorized JS origin & Authorized redirect URIs : Add your domain → Create
6) Copy the Client ID → paste below
7) Create a Drive folder → paste its ID after sign-in

User permissions:
• Share the Drive folder with other users (Editor = read+write, Viewer = read-only)
• Per-table access: create separate spreadsheets and share individually
• Add each user's email to OAuth consent screen → Test users
CRDT + Drive Sync Setup:
1) Same Google Cloud setup as Sheets (project, APIs, OAuth Client ID)
2) Paste Client ID below → Sign in
3) Create a Drive folder → paste its ID
4) Data stays in browser (instant), syncs to Drive every 30s

User permissions:
• Share the root Drive folder for full access to all tables
• Per-table access: share individual sync/{tableName}/ subfolders
• Add each user's email to OAuth consent screen → Test users
Firebase Setup:
1) Go to console.firebase.google.com → Create project
2) Firestore Database → Create database (production mode)
3) Authentication → Sign-in method → Enable Google provider (set support email)
4) Authentication → Settings → Authorized domains → Add your hosting domain
   (e.g. 127.0.0.1 for local dev, yourusername.github.io for GitHub Pages)
5) Project Settings → Your apps → Add Web app → Copy config JSON
6) Paste config below → Sign in with Google
